# 间距层级

间距本身表达结构：近的是一组，远的是另一块。界面"说不上哪里不对"时，多半是间距没有层级——所有地方都用同一个值，眼睛分不出分组。

刻度规定能取哪些值，层级规定什么关系取哪一档。

## 刻度

4px 基数：`2 / 4 / 6 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`，整页留白与首屏另可用 `64 / 96`。不写刻度以外的值；对应变量见 [tokens.css](tokens.css)。

## 语义 token

| token             | 默认值 | 用在                                                         |
| ----------------- | ------ | ------------------------------------------------------------ |
| `--space-item`    | 4px    | 一个控件或一行之内：图标与文字、标签与数值                   |
| `--space-group`   | 8px    | 同组并列：卡片之间、列表项之间、按钮组；标题与它下面的内容   |
| `--space-inset`   | 12px   | 卡片、行、小面板的内边距                                     |
| `--space-block`   | 16px   | 一个区块里的子块之间；较大容器的内边距                       |
| `--space-section` | 24px   | 不同主题的区块之间                                           |
| `--space-page`    | 16px   | 抽屉、面板、整页内容区的外边距（宽屏整页可取 24–40）         |

数值随产品密度整体缩放（宽松的营销页可整体 ×1.5–2），但相互关系不变。

## 规则

1. **由内向外只增不减**：控件内 ≤ 同组 < 容器内边距 ≤ 子块 < 区块。某一层与外一层取同一个值时，两层就分不开了。
2. **内松外紧**：容器内边距大于同级容器之间的空隙（卡片 12 内边距配 8 间距，不反过来），一组卡片才读成一组。
3. **区块之间拉得开**：区块间距 ≥ 2× 容器内边距，且 ≥ 1.5× 区块内最大的间距；簇与簇之间同理（簇间 ≥ 2× 簇内）。
4. **标题贴内容**：区块标题与内容用 `--space-group`，与上一个区块的距离由外层的 `--space-section` 给出，不在标题上另加 margin。
5. **密集区不放大，只守比例**：工具栏、菜单、表格行、列表项、编辑器与终端内部维持小档位，但仍遵守 1–3 条。
6. **写法**：容器层（页面、区块、卡片）用语义 token，叶子层用刻度；不写任意像素值间距。token 的递增关系用测试守住。

## 自查

- 把一屏里的间距值列出来：如果几乎全是同一个值，就是没有层级。
- 容器内边距是否大于同级容器之间的空隙？
- 区块之间是否明显大于区块内部？
- 标题离自己的内容近、离上一块远吗？

## 示例

```text
调整前（全 20，无层级）        调整后
页面边距     20                40
区块之间     20                48
卡片之间     20                12   ← 变小：一组卡片挨近
卡片内边距   12                24   ← 变大：内松外紧
```
